# Search Console workflow (caliber-cheats.org)

1. Open [Google Search Console](https://search.google.com/search-console) and add the **domain** property for `caliber-cheats.org` if it is not already there.
2. Under **Sitemaps**, submit: `https://caliber-cheats.org/sitemap.xml`
3. After deploys, optional: run `npm run build` so IndexNow runs when `INDEXNOW_KEY` is set.

## Useful URL patterns

| Intent | Path |
|--------|------|
| Home / Caliber cheats overview | `/` |
| Product hub | `/products/caliber/` |
| Reviews | `/reviews/` |
| Forums | `/forum/` |
